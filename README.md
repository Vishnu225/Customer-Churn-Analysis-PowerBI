# 📊 Customer Churn Analysis Dashboard

## 📌 Overview
This project presents an end-to-end **Customer Churn Analysis Dashboard** developed using **Power BI**. The dashboard analyzes customer behavior, identifies key churn drivers, and provides actionable business insights through interactive visualizations and AI-powered analytics. The project demonstrates the complete data analytics workflow, from data preparation to dashboard deployment.

---

## 🎯 Objectives
- Analyze customer churn patterns and business performance.
- Identify factors influencing customer retention and churn.
- Build an interactive dashboard for business decision-making.
- Demonstrate end-to-end data analytics using Power BI.

---

## 🛠️ Project Workflow

### 1. Data Preparation
- Imported the dataset into Power BI.
- Cleaned and transformed data using **Power Query**.
- Corrected data types and handled missing values.
- Created custom columns and customer segmentation.
- Generated bins for Monthly Charges and Total Charges.

### 2. Data Modeling & DAX
Developed DAX measures to calculate:
- Total Customers
- Customers Churned
- Active Customers
- Churn Rate
- Total Revenue
- Average Monthly Charges
- Average Customer Tenure

### 3. Dashboard Development
Designed an interactive dashboard using:
- KPI Cards
- Column Charts
- Matrix
- Donut Chart
- Treemap
- Slicers
- Navigation Buttons
- Key Influencers
- Decomposition Tree

Implemented interactive filtering, professional formatting, and consistent color themes to improve usability and user experience.

---

## 📈 Key Business Insights
- Month-to-Month contract customers exhibit the highest churn.
- Fiber Optic internet users have the highest churn among service types.
- Customers using Electronic Check as the payment method are more likely to churn.
- New customers have a higher churn tendency compared to loyal customers.
- AI visuals helped identify the major factors influencing customer churn.
